# Contributing

The contributor guide is [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md), also on the docs site: how
the code is laid out, how to build and test it, how to test a dev build on a phone or in any Linux
distro, and how pull requests work.

## Test a dev build

[docs/DEVELOPMENT.md#test-a-dev-build](docs/DEVELOPMENT.md#test-a-dev-build): `scripts/build.sh`
builds your checkout into a package and installs it, `scripts/use-release.sh` goes back to a
release.

Questions: [Discord](https://discord.gg/gBbW9mNr9P) or an issue.
